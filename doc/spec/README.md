# 專案規範說明 (Specifications)

本目錄存放已實作完成的功能規格與架構規範說明文件。

## 文件結構與章節規劃
各功能模組完成後，依章節逐步更新與撰寫：

- `01_SYSTEM_ARCHITECTURE.md`：系統整體架構、狀態管理機制與資料流。
- `02_WORK_PACKAGES.md`：工作包（看板 Kanban、甘特圖 Gantt）功能規格與交互邏輯。
- `03_RFI_TRACKER.md`：RFI（需求澄清/工程疑義）提問、狀態流轉、官方正式回覆與圖檔附件管理。
- `04_USER_ROLES.md`：使用者身分、權限與協作角色規劃。
- `05_AI_EXPANSION.md`：AI（Gemini API）輔助建築審查與規範比對功能規格。
